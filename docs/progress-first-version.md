# Progress first version

Open **Progress** (chart icon) from Today. Choose an exercise to view all available
local completed sessions, beginning with the earliest saved record; there is no
rolling date cutoff or account upload. Different catalogue exercise IDs remain
separate, including movements replaced in earlier releases.

The line plots the **heaviest logged working-set weight per completed workout**
in kg. Dates run horizontally and load vertically. It is a load history, not a
performance score: 80 kg × 6 is not automatically better than 70 kg × 10. Tap a
point, or its dated session row, to open the actual recorded sets/weights/reps.
No estimated max, success colour, automatic ranking or broad analytics is added.

Repeated dates remain separate sessions. One session renders a single point;
no completed data shows an empty state. Reps-only sessions remain inspectable
without inventing a load. Dates fall back from completion to start/scheduled time
for older records. Only explicit leading warm-up labels in set notes are excluded
from the plotted maximum; those sets remain in details. There is no structured
warm-up flag in the current set model, so older unlabelled warm-ups cannot be
identified or separated reliably. The separate workout warm-up plan is guidance,
not a set-level classification.

Shoulders gains **High Pulls** as exercise three: three sets of controlled EZ-bar
upright rows, with no invented rep target or rest prescription. Existing exercise
order, prescriptions and set rules stay intact. Startup, future clean clones and
explicit empty-session cancellation share the protected default-plan migration;
completed, active, started, entered, drafted and custom records stay unchanged.
